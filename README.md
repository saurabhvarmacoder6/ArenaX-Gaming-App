# 🎮 ArenaX — Full-Stack Esports Tournament Platform

ArenaX is a full-stack esports tournament platform designed for players to discover, join, and manage competitive gaming tournaments through a modern and responsive interface.

The project focuses on implementing real-world frontend and backend workflows including authentication, tournament management, wallet functionality, payments, player joining, notifications, and match management.

## 🚀 Live Demo

🌐 **ArenaX:** https://arena-x-gaming-app-xcmo.vercel.app/
